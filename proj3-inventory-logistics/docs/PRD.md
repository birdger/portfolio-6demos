# 项目3 PRD:进销存 + 宅急送物流系统

## 定位
贸易/仓储企业的进销存一体化 + 物流履约。**供应链/物流 PM 能力代表项目**:库存三流(资金流/物流/信息流) + 跨角色履约 + 异常管理。

## 角色与权限
| 角色 | 权限 |
|---|---|
| 管理员 admin | 全部 + 基础数据(商品/仓库/供应商) |
| 采购员 operator | 采购单创建/收货 |
| 仓管员 operator | 入库/出库/盘点 |
| 销售员 operator | 销售单创建 |
| 配送员 operator | 运单揽收/运输/派送/签收 |
| 客户 user | 下单、查运单轨迹、确认收货 |

## 功能模块
| 模块 | 说明 |
|---|---|
| 基础数据 | 商品、仓库、供应商、客户 |
| 采购管理 | 采购单→到货验收→入库(库存+);采购付款记录 |
| 销售管理 | 销售单→出库(库存-);销售收款 |
| 库存管理 | 库存台账(账面/可用/冻结)、库存流水(每笔变动留痕:类型/单据/前后值)、多仓库 |
| 盘点 | 盘点单:账面 vs 实盘,差异自动调整 |
| 物流(宅急送) | 运单:创建→揽收→运输→派送→签收;轨迹时间线;异常(拒收/丢件/破损) |
| 财务报表 | 采购成本/销售收入/毛利/应收账款 |

## 核心流程
1. 采购: 创建采购单(待收货) → 收货入库(自动生成库存流水, 库存+) → 付款
2. 销售: 创建销售单(待出库, 冻结库存) → 出库(库存-, 解冻) → 生成运单 → 签收 → 收款
3. 盘点: 建盘点单 → 录入实盘 → 差异调整(生成调整流水)
4. 运单: 创建 → 揽收 → 运输 → 派送 → 签收;任一步可标记异常(拒收→销售单回滚出库/丢件→赔偿单)

## 边界场景(必做)
1. 可用库存不足禁止出库
2. 运单状态按顺序流转,不可跳级
3. 拒收后库存回滚
4. 盘点差异自动记账并留痕
5. 每笔库存变动都能在流水里追溯(信息流)

## 关键指标
库存总量/可用库存、缺货预警(库存<安全线)、库存周转率(简化: 出货量/平均库存)、在途运单、签收时效

## 创新点
1. 库存流水账:点任何数字能看到"从哪来、到哪去"
2. 运单轨迹时间线(视觉化)
3. 盈亏报表:按商品算毛利(售价-成本),按客户/供应商汇总

## 验收清单
- [ ] 采购→入库→销售→出库→运单→签收→收款 全链路
- [ ] 库存流水可追溯每一笔变动
- [ ] 拒收回滚、盘点调整正确
- [ ] 运单轨迹时间线展示
- [ ] 缺货预警与毛利报表有数据
