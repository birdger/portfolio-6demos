# 项目4 PRD:记账系统 + 数据看板

## 定位
个人/家庭记账 + 数据化分析看板。**数据 PM 能力代表项目**:指标口径定义 + SQL 取数 + 可视化 + 留存/漏斗分析。

## 角色与权限
| 角色 | 权限 |
|---|---|
| 用户 user | 记自己账、看自己报表 |
| 管理员 admin | 看全局匿名汇总、管理分类字典、查看指标口径文档 |

## 功能模块
| 模块 | 说明 |
|---|---|
| 记账 | 收入/支出、分类、账户(现金/银行卡/微信)、备注、日期;CRUD + 搜索筛选 |
| 分类管理 | 一级/二级分类树,管理员维护(收入/支出两类字典) |
| 预算 | 每月支出预算,超额预警 |
| 数据看板 | 收支趋势(近6/12月折线)、分类占比(饼图)、月度对比(柱状)、账户分布、预算执行进度条 |
| 分析报告 | 本月结余、最大支出项、同比环比(简化: 环比上月)、支出 Top 分类 |
| 指标口径文档 | 一个页面列出所有指标的口径定义(如"结余=收入-支出",时间粒度,统计范围)——模拟真实数据平台 |
| SQL 示例页 | 展示关键取数 SQL + 结果预览,模拟数据团队工作台 |
| 留存/活跃 | 基于模拟用户行为数据(登录/记账事件),展示 D1/D7 留存、活跃漏斗 |

## 指标口径(写入文档页, 看板每个数字可点击查看口径)
| 指标 | 口径 |
|---|---|
| 本月结余 | 本月收入合计 - 本月支出合计(自然月, 本地时区) |
| 支出环比 | (本月支出 - 上月支出) / 上月支出 |
| 预算执行率 | 本月支出 / 本月预算 |
| D1留存 | 某日活跃用户中次日仍活跃的比例(模拟行为表) |
| 记账转化漏斗 | 打开App(登录)→记一笔→连续记3天 各步人数 |

## 边界场景
1. 支出金额不能为负;日期不能晚于今天(可手动选择过去)
2. 删除账目需二次确认
3. 预算超额时看板标红
4. 空数据时期图表友好提示

3. 留存分析基于模拟用户行为表,展示同期群思路
