# 项目1 PRD:图书借阅管理系统

## 定位
面向学校/社区图书馆的借阅管理后台。**后台/功能 PM 能力代表项目**:CRUD + 权限 + 流程状态机 + 报表。

## 角色与权限
| 角色 | 权限 |
|---|---|
| 管理员 admin | 全部:图书/读者/借阅/罚款/统计/日志/导入导出 |
| 操作员 operator | 借书/还书/续借办理,图书与读者查询 |
| 读者 user | 检索图书、我的借阅、续借、预约、查看逾期 |

## 功能模块
| 模块 | 说明 |
|---|---|
| 图书管理 | 增删改查:书名/ISBN/作者/分类/出版社/单价/库存;上下架;CSV 导入导出 |
| 读者管理 | 读者档案:姓名/学工号/手机号/借阅上限;状态(正常/停借) |
| 借阅管理 | 借书(库存-1)、还书(库存+1)、续借(1次/延长30天)、逾期自动计费、挂失 |
| 预约 | 图书全被借出时可预约,归还后优先通知 |
| 操作日志 | 关键操作留痕:谁在何时借/还/改 |
| 统计报表 | 借阅排行、分类占比、月度借阅趋势、逾期率、在架率 |

## 核心状态机
- 图书:在架 → 借出 → 在架 / 挂失 → 下架
- 借阅单:待借 → 借出中 → 已归还 / 逾期 / 挂失

## 边界场景(必做)
1. 库存为 0 时禁止借出(给出提示)
2. 同一读者借阅数量达上限禁止再借
3. 还书时自动计算逾期天数与罚款(示例:0.5元/天)
4. 重复还书/重复续借拦截
5. 读者处于停借状态禁止借书

## 关键指标(仪表盘展示)
借阅总量、在架率、逾期率、活跃读者数、今日借还量、罚款收入

## 创新点(与普通 CRUD 的差异)
1. 借阅趋势折线图 + 分类占比图(ECharts)
2. CSV 批量导入(带格式校验与错误行报告)
3. 逾期罚款自动结算,一个页面看清"逾期清单"

## 验收清单

- [ ] 完整借→还→续借→逾期→罚款闭环可走通
- [ ] 边界场景全部拦截并有友好提示
- [ ] 仪表盘图表有真实数据
- [ ] CSV 导入导出一键完成
