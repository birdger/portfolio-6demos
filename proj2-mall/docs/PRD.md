# 项目2 PRD:网上商城系统(仿天猫)

## 定位
B2C 电商交易闭环。**电商/交易 PM 能力代表项目**:交易链路 + 订单状态机 + 并发防护(防超卖/幂等) + 营销。

## 角色与权限
| 角色 | 权限 |
|---|---|
| 管理员 admin | 商品/分类/订单/营销/用户/数据总览 |
| 运营 operator | 商品上下架、订单处理(发货/退款审核)、优惠券配置 |
| 会员 user | 浏览、购物车、下单、支付、我的订单、评价、领券 |

## 功能模块
| 模块 | 说明 |
|---|---|
| 商品中心 | SPU(商品)/SKU(规格:颜色/尺寸/价格/库存)、分类、上下架、搜索、商品详情 |
| 购物车 | 加购、改数量、单选多选、结算 |
| 订单 | 提交订单(库存原子扣减)→支付→发货→收货→完成;超时未支付自动取消 |
| 库存 | 防超卖:UPDATE ... WHERE stock>=qty 条件扣减;下单冻结、取消回滚 |
| 支付 | 模拟支付(余额支付/沙箱页),幂等(支付单号唯一) |
| 售后 | 退款申请→审核→退款(库存回滚) |
| 营销 | 优惠券(满减/折扣)、领券、下单核销、互斥规则 |
| 评价 | 订单完成后评价(星级+文字) |
| 数据总览 | GMV/订单量/转化漏斗/热销榜/退款率 |

## 订单状态机(核心)
待付款 --支付--> 已付款 --发货--> 已发货 --确认--> 已完成
  |--超时30分钟--> 已取消
已付款 --退款申请--> 退款中 --同意--> 已退款
已发货 --退货--> 退款中

## 边界场景(必做)
1. 库存不足时下单被拒;多人同时抢最后1件不超卖(条件更新+重试提示)
2. 支付按钮重复点击/重复提交 → 幂等,只成功一次
3. 超时未支付订单自动取消并回滚库存(后台线程扫描)
4. 优惠券互斥:满减券与折扣券不可同用
5. 退款后库存回滚,订单不可再支付
6. 商品下架后购物车/下单拦截

## 关键指标(仪表盘)
GMV、订单量、转化率(浏览→下单→支付漏斗)、客单价、退款率、热销 Top5
